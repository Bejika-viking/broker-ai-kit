# Broker AI Kit

Инструменты для брокеров зарубежной недвижимости, которые работают с клиентами, проверяющими всё через нейросети.

**Набор обновляется.** Мы дорабатываем инструменты по отзывам брокеров и результатам тестов. Что изменилось — в [CHANGELOG.md](CHANGELOG.md). Конструктор сам проверяет, вышла ли новая версия, и предлагает обновиться. Текущая версия — в файле [VERSION](VERSION).

## Что внутри

| Инструмент | Что делает |
|---|---|
| **Конструктор КП** | КП, сравнения и подборки объектов в двух слоях: для клиента и для нейросети, которой клиент покажет документ. Инфографика, психология цены, защита от выдуманных цифр. Режимы: профиль брокера и дизайн, КП по объекту, сравнение, подборка под критерий, ежемесячная подборка для соцсетей, пересборка после возражения |
| **Humanizer RU** | Убирает признаки AI-генерации из русского текста: КП, постов, писем, сценариев |
| **Чек-лист «Как попасть в ответ нейросети»** | Пошаговый план и 192 площадки с прямыми ссылками на регистрацию: [PDF](checklists/01-kak-popast-v-otvet-neiroseti.pdf) |
| **Чек-лист «Клиент советуется с нейросетью»** | Что делать, когда клиент молча проверяет вас в ChatGPT: [PDF](checklists/02-klient-sovetuetsya-s-neirosetyu.pdf) |

## Где работает лучше

Лучший результат — в **Claude**. Он читает правила конструктора целиком на каждом шаге.

ChatGPT и Gemini выполняют длинные правила хуже: справочные файлы они не читают целиком, а ищут в них отдельные фрагменты. Главные правила продублированы в инструкции, но часть деталей может теряться. Результаты сравнения на одинаковых тестовых клиентах: [вставить].

## Установка

### Claude — Pro, Max, Team, Enterprise
1. Customize → Plugins → Add → Add marketplace → Add from a repository
2. Вставьте: `Bejika-viking/broker-ai-kit`
3. Установите плагин **broker-ai-kit**

В настройках должно быть включено «Code execution and file creation».

### Claude — бесплатный тариф
1. Скачайте [dist/kp-constructor.zip](dist/kp-constructor.zip) и, если нужен, [dist/humanizer-ru.zip](dist/humanizer-ru.zip)
2. Настройки → Capabilities: включите «Code execution and file creation»
3. Customize → Skills → «+» → Create skill → Upload a skill → выберите архив

Чтобы получить обновление, скачайте архив заново и загрузите поверх старого.

### Claude Code
```
/plugin marketplace add Bejika-viking/broker-ai-kit
/plugin install broker-ai-kit@broker-ai-kit
```
Автообновление: `/plugin` → Marketplaces → broker-ai-kit → Enable auto-update.

## С чего начать
1. «Настроим профиль брокера» — один раз: соцсети, фото, брендбук, контакты, аналитика
2. Приложите материалы по объекту и напишите, что нужно: КП, сравнение, подборку
3. Ответьте только на те вопросы, которые задаст конструктор
4. Перед отправкой клиенту проверьте все пометки [заполнить] и [проверить]
